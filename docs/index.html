Project Focus

Built for MLX-native 3DGS experiments

  • MLX training and rendering Ports FastGS rendering and training from PyTorch and CUDA shading language into MLX C++ and Metal shading language with OpenAI Codex collaboration, with a path toward MLX-Swift support.
  • Metal custom extensions Provides a basic MLX C++ template by implementing MLX Primitive, connecting forward rendering and backward training as a reusable example for future extensions.
  • FastGS gradient workflow 3DGS relies on PyTorch retain_grad() to keep selected gradients, which is difficult to port to MLX. FastGS instead trains with viewspace_points parameters to obtain the information needed for post-training processing.
  • Scanner dataset pipeline Supports iPhone LiDAR exports, using Point Cloud and image data from 3D Scanner App for training.
